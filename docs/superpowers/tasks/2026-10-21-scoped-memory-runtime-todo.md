## 3. 实现任务

### P0：批准和运行约束

- [ ] 用户确认 spec；将不确定的预算、历史清理和 cwd 策略修订到明确版本。
- [ ] 检查当前 Node、Bun、包运行和二进制发布方式的 SQLite 支持，选择最小兼容方案。
- [ ] 若必须增加依赖，先审查版本与生命周期脚本，再按仓库规范更新 lockfile。
- [ ] 记录本轮选择不覆盖远程控制、RAG、多媒体或人设自动评分。

### P1：项目身份和 scope

- [ ] 实现绝对 cwd／realpath／目录哈希／可读名称，保留完整原始路径和规范路径。
- [ ] 保留六种 type，独立增加 persona/project scope，不建立第七类型。
- [ ] 为稳定记忆 ID、scope、project_id、主题和状态定义统一契约。
- [ ] 固定会话的执行 cwd 与 project_id，标签切换不修改后台任务归属。
- [ ] 规定未指定 scope 时的兼容行为；不得把所有工作记录默认落进 persona。

### P2：SQLite 与恢复

- [ ] 实现 spec 第8节的必要表、schema 迁移和短事务。
- [ ] 人设及每项目版本独立推进；删除／改名有变化记录。
- [ ] 消息接收、快照、队列、已交付凭据分开存储。
- [ ] 文件双写有 operation ID、日志及幂等恢复。
- [ ] 多进程忙碌处理和有界重试，不长时间锁住模型生成过程。
- [ ] 同一原生会话的执行权有保护，避免两个 bridge 同时写同一历史。

### P3：统一更新与迁移

- [ ] 人设与项目复用同一个写入通道，scope 参数决定落点及索引。
- [ ] 既有 read 工具保持不变；受管文件 write/edit 和 memory_write 使用同一检查。
- [ ] 同记录版本冲突拒绝覆盖；不同记录不互相阻塞或丢弃。
- [ ] 增加内容哈希核对，识别人工编辑和删除。
- [ ] 生成内部运行目录 dry-run；不访问 `.neko_mem` 或外部 AGENTS.md。
- [ ] 备份并验证恢复能力，迁移六种类型、日期、状态、正文和历史关联。
- [ ] 原记录工作项目不明确时列出待确认，禁止按当前 cwd 猜测归属。
- [ ] 生成文件重命名映射，旧聊天不重写。
- [ ] SQLite 导入 JSON 连续状态、活动、衣橱及会话目录，可重复执行。
- [ ] 检查新旧程序并行写保护；回退不得丢迁移后新事实。

### P4：消息与变化通知

- [ ] HTTP 接收时固定时间／时区、版本、截止序号和模型快照，持久化成功后确认接收。
- [ ] 稳定消息 ID 去重，重试不增加第二次 user_query。
- [ ] 通知查询按 persona＋当前 project 过滤；其他项目正文不得泄漏。
- [ ] 同一会话已知工具结果不重复通知，后台未交付结果仍需补交。
- [ ] 取消队列不丢变化；后续快照已冻结时使用独立补偿上下文。
- [ ] 连续空变化不生成占位块；压缩后丢背景则重新提供必要快照。
- [ ] 21天清理活动；当前记忆版本仍可比较，不修改历史快照。
- [ ] 活动预算超限有明确省略与来源，不能静默声称全读。

### P5：记忆价值与增长

- [ ] 目录提供类别、明确主题、简短用途、状态、路径及版本。
- [ ] 移除每轮自动关键词召回和重复常驻背景，不偷偷换成别的自动检索。
- [ ] 模型可局部或全文阅读，不强制整模块或全库。
- [ ] 默认不运行额外模型提炼请求；可选摘要不成为普通 query 的必要步骤。
- [ ] 工作记忆仅保存长远、复用信息；普通进度和工具输出不记。
- [ ] 人设记忆较宽松；whisper 保持主观语义，不变成用户承诺。
- [ ] 同主题更新、重复合并、承诺状态和旧记录整合有明确规则。
- [ ] active/history/数据库分别统计容量，超限有整理或明确失败，不无限自动增长。

### P6：运行状态与表达钩子

- [ ] 连续状态区分 persona/project，带版本、来源、时间与有效期。
- [ ] 服装定义、锁定和当前项迁到 SQLite，六小时按全局用户消息计算。
- [ ] 新会话沿用当前衣服；同版本不反复注入；空衣橱跳过。
- [ ] StyleBank 仅按受支持的真实工具事件和结果匹配，支持冷却。
- [ ] 提示与工具输出分离；规则空、禁用、失败、复杂命令都不误触发。
- [ ] 服装和 StyleBank 不改写普通工作产物，不启用图像生成。

### P7：TUI 和桥接

- [ ] 会话树按真实项目归组，下方有最近；项目同名也能区分。
- [ ] 点击先加载正确会话，再进入既有顶部标签；已开标签复用。
- [ ] 新建、搜索、重命名、归档、删除、运行状态及恢复接口逐一核对。
- [ ] 多项目切换后模型、cwd、历史、队列、记忆 scope 均指向当前会话。
- [ ] 运行中切走不取消任务；明确中断才触发后台 abort。
- [ ] 状态／立绘区域留空；私人正文不直接显示在侧栏。
- [ ] 窄终端、键盘访问、失败重试和长列表可用。
- [ ] 列出移植前端所有可见功能的支持状态；没有后端实现的入口明确不可用，不返回假成功。
