## 五、关键坑档案（新人必读）

- **bundle 打包链**：改 src → `cd packages/coding-agent && npm run build`（tsc）→ 仓库根 `node scripts/build-coding-agent-bundle.mjs`。**漏 tsc 直接 bundle 会打进旧代码穿新版本号**（踩过两次）。
- **build 副作用**：`npm run build` 会重新生成 `packages/ai/src/models.generated.ts`（拉上游新目录）——若 check 突然爆 ai 测试类型错，先 `git checkout -- packages/ai/src/models.generated.ts` 排除，再查测试是否 fork 旧版。
- U+29FE 是假圆点，⏺ 真身 U+23FA。
- settings.json 默认模型必须拆两字段（见上）。
- 测试 harness 默认内存会话无文件——truncate 类测试需 `SessionManager.create(root, root)` 显式落盘。
- 记忆验收测试用 **project 作用域**装测试事实（cap 有余量可整体清除），恢复以**演化前实时基线**为准（备份时点可能更早）；恢复后 diff 六本书确认零变化。
- 面板/组件内文本行要 `wrapMode none＋truncate`，否则长文本顶开容器。
- bun 在 `~/.bun/bin/bun`（vendor 删后基本不用了）；tmux 未安装，pty 用 `script -qec`。
